# Instagram ads research (Instadata)

## Setup
Uses the `instadata` MCP server (https://mcp.instadata.dev). Sign in with OAuth when prompted, or set header `Authorization: Bearer ik_live_...` (key at https://instadata.dev/app/keys). 25 free credits on signup; then $5 per 1,000 credits. Read-only, public data only.

## Workflow
1. Keyword: ads search (3 credits/ad) returns Meta Ad Library ads with advertiser Instagram handle.
2. Advertiser: ads by page — pass Facebook Page URL or Ad Library page URL (3 credits/ad).
3. Creator–brand deals: profile collaborations (3 credits/row) for paid-partnership posts.
4. Summarize angles, offers, CTAs, run dates and formats; link every ad. Confirm cost before pulling >30 ads.
